토큰을 입력해 주세요

이 보관함은 비공개 저장소 gulgul-assets의 파일을 보여 주고, 휴대폰에서 파일을 올릴 수 있습니다. GitHub 토큰을 한 번 입력하면 이 기기에만 저장됩니다.

  1. GitHub 토큰 만들기 화면을 엽니다 (Fine-grained token).
  2. Repository access에서 Only select repositories를 고르고 gulgul-assets만 선택합니다.
  3. Permissions > Repository permissions > Contents를 Read and write로 합니다. 보기만 할 때는 Read-only로도 됩니다. 올리기에는 쓰기 권한이 필요합니다.
  4. 만든 토큰(github_pat_...)을 아래에 붙여넣고 저장합니다.

토큰은 이 브라우저에만 저장되고 GitHub API 호출에만 쓰입니다. 기기를 잃어버리면 GitHub에서 토큰을 삭제해 주세요. 오른쪽 위 더보기(점 세 개) 메뉴의 '토큰 바꾸기' 화면에서 이 기기의 토큰을 지울 수 있습니다. 올리기 중에는 토큰으로 저장소에 파일을 쓰므로 쓰기 권한 토큰은 꼭 이 기기에만 보관해 주세요.
