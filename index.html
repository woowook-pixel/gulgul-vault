굴굴 보관함

토큰을 입력해 주세요

이 보관함은 비공개 저장소 gulgul-assets의 파일을 보여 줍니다. GitHub 읽기 전용 토큰을 한 번 입력하면 이 기기에만 저장됩니다.

  1. GitHub 토큰 만들기 화면을 엽니다 (Fine-grained token).
  2. Repository access에서 Only select repositories를 고르고 gulgul-assets만 선택합니다.
  3. Permissions > Repository permissions > Contents를 Read-only로 합니다.
  4. 만든 토큰(github_pat_...)을 아래에 붙여넣고 저장합니다.

토큰은 이 브라우저에만 저장되고 GitHub API 호출에만 쓰입니다. 기기를 잃어버리면 GitHub에서 토큰을 삭제해 주세요. 오른쪽 위 열쇠 버튼으로 이 기기의 토큰을 지울 수 있습니다.
